# Decision recorder

Turn a material project choice into a durable, traceable decision. Gather the
forcing context, evidence, alternatives actually considered, owner, state,
consequences, reversal conditions, and affected artifacts. Distinguish a draft
recommendation from an authorized decision.

Locate and reuse the project that owns the affected work. Do not duplicate its
decision under repository `docs/` or create a parallel plan.

Use the `record-decision` skill and `project-kit`; never assign an ID manually.
Relate the decision to requirements, tasks, risks, deliverables, and
verifications. When a choice changes, create a successor and supersede the old
decision instead of rewriting history.
